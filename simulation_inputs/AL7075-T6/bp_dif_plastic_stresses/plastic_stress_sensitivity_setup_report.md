# Plastic/yield-stress sensitivity setup

Created from `simulation_inputs/AL7075-T6/baseline_parameters.xml` using the same included mesh file and baseline settings, including `mesh_max_edge_length = 0.00328`.

## What varies

Only the Abaqus elastic-perfectly-plastic yield stresses in `<plastic_stresses>` vary. Elastic constants stay fixed at `E = 71000 MPa`, `nu = 0.33`; displacement stays `0.01`; mesh/domain/volume fractions/sizes stay from `baseline_mesh.xml`.

Range used: 350-710 MPa, based on the baseline yield stresses `350, 470, 710, 710`.

## Files created

- Summary CSV: `simulation_inputs/AL7075-T6/bp_dif_plastic_stresses/case_study_overview_plastic_stress.csv`
- Summary + ROM metrics CSV: `simulation_inputs/AL7075-T6/bp_dif_plastic_stresses/case_study_overview_plastic_stress_with_rom_metrics.csv`
- XML cases: 20 files in `simulation_inputs/AL7075-T6/bp_dif_plastic_stresses`
- Abaqus `.inp` cases generated by reusing the baseline mesh and replacing material plastic blocks: 20 files in `simulation_outputs/plastic_stress_sensitivity`

## Design-only quick insight before Abaqus solve

Because the baseline phase fractions are `[0.1, 0.1, 0.4, 0.4]`, phases 3 and 4 dominate a simple phase-fraction-weighted ROM estimate. The design's weighted-yield metric spans `412.4` to `641.1` MPa, compared with the baseline weighted value of `650.0` MPa.

Lowest expected response cases by this ROM metric:

- Case 16: ROM=412.4 MPa, stresses=(399, 709, 351, 403)
- Case 02: ROM=424.7 MPa, stresses=(421, 538, 370, 452)
- Case 11: ROM=455.2 MPa, stresses=(480, 656, 484, 370)
- Case 08: ROM=480.0 MPa, stresses=(694, 398, 408, 519)
- Case 15: ROM=493.7 MPa, stresses=(613, 384, 555, 430)

Highest expected response cases by this ROM metric:

- Case 10: ROM=585.2 MPa, stresses=(400, 404, 593, 669)
- Case 17: ROM=586.0 MPa, stresses=(455, 609, 659, 540)
- Case 20: ROM=590.1 MPa, stresses=(564, 601, 539, 645)
- Case 05: ROM=635.7 MPa, stresses=(499, 658, 607, 693)
- Case 19: ROM=641.1 MPa, stresses=(619, 700, 653, 620)

Important caveat: this is only a pre-solve design ranking. Real Abaqus curves may deviate because morphology, load sharing, and local yielding are not captured by this simple weighted-yield metric.
