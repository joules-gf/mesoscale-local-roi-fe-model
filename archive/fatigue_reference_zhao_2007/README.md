# Fatigue reference archive — AA7075-T651 / Zhao 2007

This folder groups the older fatigue-reference material that used to live in `01_Secondary_Scripts/`.

Contents:

- `fatigue_AA7075-T651_Zhao_2007.csv` — fatigue data table used by the comparison scripts/figures.
- `fatigue_figures/` — generated fatigue-reference figures from that data.
- `stress_strain_fatigue_approach_comparison_saved_figures.py` — script version that saved the fatigue/stress-strain comparison figures.

These files are retained for provenance/reference, but they are not part of the active simulation/ROI workflow.
